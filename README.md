## Code

This repository holds section data only. The executable code that used to live here moved to
[`red-cup-engineering/artificial-intelligence-research-notebook-services`](https://github.com/red-cup-engineering/artificial-intelligence-research-notebook-services) (received 2026-10-24 from
`lenticule-science/artificial-intelligence-research-notebook-services@dbcdb1c1bab8`). That engine reads this data from `SECTION_ROOT` (default: its current working directory),
so point `SECTION_ROOT` at a checkout of this repository.

## Public source-attributed research objects

The [research-object directory](content/research-objects/) holds public data and declarative
source/evidence contracts for openly inspectable findings, separate from the
executable notebook engine. These are not automatically accepted papers or
model replications.

- [Qwen neuron–persona steering, October 28, 2026](content/research-objects/qwen-neuron-personas-2026-10-28/README.md):
  four reported experimental settings across Qwen3.5-4B and Qwen3-8B, with
  attributed counts, explicit limitations, an independent verification demand,
  and a reusable [experiment evidence JSON Schema](content/research-objects/experiment-evidence-v1.schema.json).
